# 开源文件边界

本项目只包含网页版。发布范围为 `box/`、`config/`、`templates/`、`static/`、测试、通用 Compose/Caddy 配置、示例配置和说明文档。

以下内容保持私有，不随源码发布：

- `.env`、`.env.*`、`.env-*`，只有 `.env.example` 可以发布。
- `data/`、数据库、备份、初始登录资料、签名密钥和 OAuth 缓存。
- 编辑器配置、虚拟环境、编译缓存、生成静态资源和截图。
- 其他客户端源码、专用接口、身份模型和通知逻辑。

示例使用 `ask.example.com`、`站长` 等通用值；真实通知密钥、邮件凭据和签名密钥由部署者自行配置。代码中的模拟测试凭据不授予任何外部服务权限。

GitHub 发布前先核对文件：

```sh
git status --short --untracked-files=all
git add --dry-run .
```

确认提交内容后才暂存和提交。忽略规则不会移除已跟踪文件或历史中的秘密。如果真实凭据曾被公开，需要撤销或更换凭据，再处理仓库历史；仅删除当前文件不足以消除泄露。

本版用于新安装，不包含生产数据库。不要用其迁移链直接升级其他版本的已有数据；需要迁移时应先备份并单独制定迁移步骤。
