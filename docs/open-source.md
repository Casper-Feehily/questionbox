# 开源文件边界

发布范围包含网站、微信小程序、后端 API、测试、通用 Compose/Caddy 配置及说明文档，遵循仓库现有 GPLv3 许可。

以下内容不随源码发布：

- `.env` 及变体（仅 `.env.example` 例外），真实 AppSecret、通知密钥、邮件凭据与 OAuth 令牌。
- `data/`、数据库、备份、账户资料、用户问题、邮箱、微信标识及会话数据。
- 微信开发者工具 `project.private.config.json`、嵌套 Git 元数据、编辑器配置与依赖缓存。
- 内部服务器地址、SSH 别名、生产部署脚本与运维、上传确认记录。

公开默认值使用 `站长`、`ask.example.com` 与 `touristappid`。小程序默认 `demo: true`；示例便签为源码中的模拟内容，不包含运行数据库的提问。模拟测试凭据不授予外部服务权限。通用分享封面为项目静态素材。

GitHub 发布前检查 `git status --short --untracked-files=all` 与 `git add --dry-run .`，扫描全部待发布文件及历史。忽略规则不能移除已跟踪文件或历史秘密；真实凭据一旦泄露，应撤销或轮换。

本仓库保留旧开源版迁移 `0004_barkjob`，微信模型从 `0005_wechat` 引入。升级先备份再迁移。其他版本迁移链可能不同，需要单独评估，不能直接混用。
